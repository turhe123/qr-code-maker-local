    How it works

    1. Pick what to share. Choose Link, Wi-Fi, Contact, Text, Email, Phone or SMS and fill in the fields. The preview redraws as you type.
    2. Tune it if you like. Raise error correction for print that may get scuffed, set the size and quiet zone, and pick colours. A warning appears if the contrast could stop phones from reading it.
    3. Save PNG or SVG. The file is drawn on your device. The data sits inside the code itself, so it keeps working with no account, redirect or expiry date.

    Questions, answered

    Will these QR codes ever stop working?

    No. These are static codes: the link, Wi-Fi details or contact card are encoded directly in the black and white squares. There is no short link or redirect server in between, so nothing can expire, be switched off or be tracked. The trade-off is that you cannot edit a printed code later; make a new one if the content changes.

    Is my Wi-Fi password or contact data uploaded anywhere?

    No. Static QR Code Maker runs entirely in your browser. What you type stays in memory on your device, the code is computed with JavaScript, and nothing is sent to a server. You can disconnect from the internet and it keeps working.

    PNG or SVG, which should I download?

    PNG is a normal image at the pixel size you choose, good for documents, slides and messages. SVG is a vector file that stays sharp at any size, which is best for print shops, signs and menus. Both use crisp square modules with no blur.

    Why does it say my content is too long?

    A QR code holds at most about 2,900 bytes at Low error correction and about 1,270 at High. Emoji and non-Latin letters take 2 to 4 bytes each. Shorten the text or lower the error correction level. Long codes also get dense, so keep printed codes short where you can.

    Is it really free, and does it work offline?

    Yes to both. It is open source under the MIT license, with no account, no limits, no watermark and no ads. After your first visit the page is cached by a service worker, so it loads without a connection, and you can install it from your browser's menu as an app. If it saves you a subscription, you can say thanks on Ko-fi.
